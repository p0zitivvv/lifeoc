# LIFE OS — Персональная система управления повседневной жизнью
> Personal Discipline, Productivity, Fitness, Nutrition & Habit Management Platform

LIFE OS — это работающее, адаптивное веб-приложение (PWA) уровня премиального SaaS для системного управления личной дисциплиной: учебой, привычками, домашними тренировками, питанием, водным балансом, экранным временем, сном и ежедневным расписанием.

---

## 1. Что реально реализовано

### 🧠 Умный детерминированный автопланировщик (Core Business Logic)
- **Распределение времени**: алгоритм рассчитывает доступные интервалы между подъемом и сном, исключает обязательные блоки (учеба/работа) и время дороги с буфером.
- **Приоритеты**: сначала размещаются задачи с фиксированным временем, затем регулярные привычки (утренние/вечерние окна), приоритетные учебные сессии, тренировки и гибкие задачи.
- **Вставки пауз**: после учебных блоков от 45 минут автоматически добавляются перерывы.
- **Пересчет дня без разрушения истории (Recalculate Day)**: кнопка пересчета сохраняет выполненные задачи на месте, анализирует оставшееся до сна время и перераспределяет только незавершенные задачи без дублирования.
- **Обработка перегрузки (Overload Detection)**: если задачи не помещаются в день, система не забирает время сна, а честно предупреждает пользователя о конфликте и предлагает варианты разгрузки.

### 📋 Менеджер задач (Task Manager)
- Создание, редактирование, удаление, завершение, перенос на завтра (+1 день).
- Фиксированное время vs гибкое автоматическое планирование.
- Приоритеты (urgent, high, medium, low) и категории (учеба, фитнес, питание, уход, работа, быт, отдых, другое).
- Подзадачи (чек-листы).
- Фильтрация: Сегодня, Предстоящие, Все, Выполненные, по категориям.

### ✨ Трекер привычек (Habits & Self-Care)
- 1-клик быстрое закрытие привычек за сегодня.
- 7-дневная сетка истории выполнения.
- Типы измерений: Да/Нет (boolean), Длительность (минуты), Количество (страницы, разы), Объем (мл).
- Категории: Уход за собой (утреннее/вечернее умывание, чистка зубов), Микропривычки (уборка стола, проветривание, чтение, разминка), Холодный душ (опционально, без принуждения), Питание, Вода, Экранный режим, Сон, Пользовательские.
- Архивация и восстановление без потери истории.
- Нетоксичная мотивация: единичный пропуск не обнуляет серию и историю достижений.

### 🎓 Учёба и Фокус-таймер (Education & Focus Timer)
- Предметы (Математика, Информатика, Английский и др.) с целевыми часами в неделю и датами экзаменов.
- Конкретные измеримые темы и задачи ("Решить 10 задач по тригонометрии", "Повторить 15 слов").
- **Таймер фокуса (Pomodoro)**: режимы 25/5/15 мин и настраиваемые интервалы.
- **Точность по таймстемпам**: вычисление времени через timestamps сохраняет состояние таймера при перезагрузке страницы.
- Учет только реального прошедшего времени в секундах, запись сессий в журнал.

### 🏋️ Тренировки (Fitness)
- Базовые упражнения: отжимания, подтягивания, приседания, планка, работа с гантелями, свои упражнения.
- Учет сетов: повторения, рабочий вес (кг), секунды, чекбоксы завершения.
- **Интерактивный таймер отдыха**: 60-секундный таймер между подходами.
- Учет дней восстановления (плановые дни отдыха).
- Оценка самочувствия (1-5) и заметки. Запись фактического объема.

### 🥗 Питание и привычка снижения сахара (Nutrition)
- Завтрак, обед, ужин, перекус. Быстрая запись блюд и порций.
- Необязательные калории и белки без навязчивого подсчета.
- Автодополнение и поиск по ранее введенным блюдам.
- **Привычка снижения добавленного сахара**: выбор комфортной стратегии (меньше сладких напитков, сокращение сладких перекусов, постепенное уменьшение ложек сахара, баланс рациона). Четкое отличие добавленного сахара от фруктов и молочных продуктов. Никакого стыда и чувства вины.

### 💧 Водный баланс (Hydration)
- Индивидуальная цель (по умолчанию 2000 мл).
- Быстрые кнопки добавления: +200, +250, +350, +500 мл.
- Отмена последней записи в один клик.
- Предупреждение о безопасности при чрезмерной цели (> 4.2 л).
- История записей за день и прогресс-бар.

### 📵 Цифровая дисциплина (Digital Discipline)
- Правило "Без экрана после 22:00" (настраиваемое время).
- Чек-лист вечернего цифрового покоя (завершить дела, убрать телефон, подготовить одежду, вечерняя гигиена).
- Еженедельный цифровой детокс (воскресенье) с сохранением экстренной связи.
- Прозрачность: объяснение ограничений веб-платформы.

### 🛌 Сон и восстановление (Recovery)
- Целевой график (время отхода и подъема).
- Дневник сна: фактическое время, субъективная оценка (1-5 звезд), самочувствие при пробуждении (бодрый, нормальное, уставший, разбитый).

### 📅 Календарь
- Режимы: День, Неделя, Месяц.
- Отображение задач, тренировок, учебных сессий и привычек.
- Навигация по датам.

### 🔔 Умные уведомления (Smart Notifications)
- Встроенный In-App центр уведомлений с бейджем непрочитанных.
- Режим тишины (ночью с 22:30 до 07:00).
- Поддержка Web Push API и Service Worker.

### 📊 Честная аналитика (Analytics)
- Периоды: 7, 30, 90 дней.
- **Task Completion Rate**: `выполненные / подлежащие учету × 100` (строго исключены будущие и отмененные задачи).
- **Study Completion Rate**: `фактическое время / плановое × 100`.
- **Habit Completion Rate**: `выполненные / наступившие по расписанию × 100`.
- **Серии активности (Streaks)**: непрерывная серия, лучшая серия, общее число активных дней.
- Защита от деления на ноль: отображение "Нет данных" при пустом знаменателе.

### ⚡ Быстрый 5-секундный чек-ин (Daily Check-In)
- Оценка энергии (1-5), доступное время, особые обстоятельства.
- Тумблер "Снизить нагрузку сегодня" (автоматически пересчитывает план в щадящий режим).

### ⚙️ Настройки и Резервное копирование (Settings & Data Backup)
- Полный экспорт всей базы данных в единый файл `JSON`.
- Импорт и восстановление данных из `JSON`.
- Сброс базы данных с диалогом подтверждения.

### 📱 PWA & Offline First
- Установка на главный экран смартфона (Web App Manifest, standalone mode, иконки 192px и 512px).
- Service Worker с кэшированием статики и fallback для работы без сети.
- Хранение данных в IndexedDB (Dexie).

## 2. Стек технологий

- **Frontend**: Next.js 15 (App Router), React 19, TypeScript 5.7.
- **Стилизация**: Tailwind CSS 3.4 (минималистичный dark UI, графитовые оттенки `#09090b` / `#121215`, лаймовый акцент `#84cc16`).
- **Иконки**: Lucide React.
- **Локальное хранилище**: IndexedDB (Dexie 4.0) — полностью автономный режим без необходимости внешних серверов.
- **Облачная база (готовность)**: Supabase / PostgreSQL с полной схемой, индексами и Row Level Security (RLS) в `src/lib/storage/supabaseSchema.sql`.
- **Тестирование**: Vitest.

## 4. Как запустить локально

1. Убедитесь, что установлена Node.js (рекомендуется v18+ или v20+).
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите тесты бизнес-логики:
   ```bash
   npm test
   ```
4. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
5. Откройте в браузере: `http://localhost:3000`.

Для сборки production-версии:
```bash
npm run build
npm start
```

## 5. Переменные окружения

LIFE OS работает **на 100% локально** в браузере через IndexedDB без необходимости внешних ключей.

Если вы хотите подключить облачную синхронизацию через Supabase и удаленные Web Push уведомления, скопируйте `.env.example` в `.env.local`:
```bash
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
NEXT_PUBLIC_VAPID_PUBLIC_KEY=your-vapid-public-key-here
VAPID_PRIVATE_KEY=your-vapid-private-key-here
VAPID_SUBJECT=mailto:admin@lifeos.app
```

## 6. Настройка Supabase и базы данных

В проекте подготовлен готовый файл миграции: `src/lib/storage/supabaseSchema.sql`.

Для настройки:
1. Создайте проект в [Supabase](https://supabase.com).
2. Перейдите в раздел **SQL Editor**.
3. Скопируйте и выполните содержимое файла `src/lib/storage/supabaseSchema.sql`.
4. Скрипт автоматически создаст:
   - Таблицы `profiles`, `tasks`, `habits`, `habit_logs`, `subjects`, `study_sessions`, `workout_exercises`, `workout_sessions`, `meals`, `water_logs`, `digital_discipline_logs`, `sleep_logs`, `daily_checkins`, `daily_plans`, `notifications`.
   - Внешние ключи с каскадным удалением при удалении пользователя.
   - Ограничения целостности (unique constraints по датам).
   - Индексы для быстрой фильтрации по пользователю и датам.
   - Политики безопасности **Row Level Security (RLS)**: пользователи имеют доступ исключительно к своим собственным данным (`auth.uid() = user_id`).

## 7. Авторизация

- В локальном режиме авторизация не требуется — приложение сохраняет данные в локальной песочнице браузера пользователя.
- При подключении Supabase Auth используется встроенный провайдер `auth.users`, к которому привязаны внешние ключи всех таблиц схемы.

## 8. PWA и установка на смартфон

- Файл манифеста: `public/manifest.json`.
- Иконки PWA: `public/icons/icon-192.svg` и `public/icons/icon-512.svg`.
- Service worker: `public/sw.js` автоматически регистрируется при загрузке.
